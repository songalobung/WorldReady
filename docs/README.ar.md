## 🎯 الفكرة الأساسية

> **زوّد وكيل الذكاء الاصطناعي البرمجي بمستودع الكود، وسيقوم WorldReady بتحديد أخطاء التدويل، وتوضيح أثرها، واقتراح حلول برمجية آمنة، وإثبات صحة النتيجة باختبارات تنفيذية.**

الميزة الحاسمة هي **الإثبات، لا مجرد النصيحة**.

لا يكفي أن يقول المساعد الذكي: *"تخطيط صفحتك باللغة العربية يبدو ممتازاً"*. يوفّر WorldReady أدلة حقيقية بأرقام الأسطر ونتائج فحص شجرة الرموز المجردة (AST) واختبارات معيارية لا تحتمل الخطأ.

---

## 🌟 المزايا الجوهرية الخمس

1. **تدقيق مستقل عن إطار العمل**: لا نعتمد على مطابقة النصوص التعبيرية (Regex) الهشة، بل يحلل WorldReady شجرة AST لملفات TypeScript و React و HTML و CSS و JSON دون المساس ببنية تطبيقك.
2. **دعم استثنائي للكتابة من اليمين إلى اليسار (RTL)**: اتجاه النص خاصية تعود إلى **نظام الكتابة (Script)** وليس مجرد رمز اللغة. يفحص WorldReady وسوم `dir="rtl"`، والخصائص المادية في CSS مثل (`margin-left` و `padding-right`) ويوصي بخصائص CSS المنطقية (`margin-inline-start`)، بالإضافة إلى عزل النصوص ثنائية الاتجاه عبر `<bdi>`.
3. **اختبارات قواعد اللغات الواقعية**: مدعومة بقواعد بيانات معايير يونيكود CLDR، للتحقق من صِيَغ التواريخ، والأرقام، والعملات، وقواعد الجموع المعقدة في اللغة العربية (مفرد، مثنى، جمع قلة، جمع كثرة، وغيرها).
4. **حلقة الإصلاح والتحقق المكتملة**: `تدقيق ➔ شرح ➔ اقتراح الحل ➔ تطبيق الكود ➔ إعادة التدقيق للتأكد من عدم وجود أخطاء جديدة`.
5. **تنفيذ محلي بالكامل دون ربط بأي واجهة ذكاء اصطناعي**: يعمل المحرك محلياً 100% دون الحاجة إلى مفاتيح API خارجية لضمان سرية الكود وأمانه.

## ⚡ البدء السريع

```bash
# 1. تهيئة ملف الإعدادات تلقائياً
npx worldready init

# 2. بدء تدقيق التدويل ودعم الكتابة من اليمين إلى اليسار (RTL)
npx worldready audit

# 3. التدقيق على لغات محددة
npx worldready audit --locales en,ar,fr,ja

# 4. توليد تقرير أمني بتنسيق SARIF لمنصة GitHub
npx worldready audit --format sarif -o worldready.sarif

# 5. تشغيل الفحص في خوادم الاندماج المستمر (CI)
npx worldready ci

# 6. اختبار مرونة الواجهة عبر التدويل التجريبي (Pseudo-localization)
npx worldready test --locale ar-XB
```
